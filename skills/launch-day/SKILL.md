# Launch day

The day is about being present: posts go out as planned, every comment gets a
real answer, and nothing breaks unnoticed.

## The evening before

- Everything approved: posts, images, video, emails - nothing written on the day
  except replies.
- Sign-up or install tested end to end, on desktop and phone.
- The team (or just the founder) knows who answers which channel and when they
  sleep; set up alerts for errors and sign-ups.
- Know the time each post goes out (in the platform's time zone).

## Run sheet

Write one, with times, for this launch. A typical shape:

| When | What |
|---|---|
| Start of the main channel's day | Post on the main channel (for example Product Hunt at 12:01am Pacific, or Show HN on a weekday morning US time) and add the first comment |
| +30 min | Personal messages and the launch email to people who already care (users, friends, list) - telling them, asking for feedback, never for votes |
| Every 30-60 min | Answer every comment and question on every channel, in the founder's own words |
| Morning (audience's time) | X and LinkedIn posts, each written for its platform |
| All day | Watch sign-ups, errors, support messages; fix fast; say publicly when something is fixed |
| End of day | Thank people; note numbers (visits, sign-ups, comments, feedback themes) |

## While it runs

- Replies: thank, answer the actual question, be honest about limits and what is
  coming. Never argue; never delete fair criticism.
- Problems: if something breaks, fix it or put up a clear notice, then reply where
  people reported it.
- Do not ask for upvotes, do not use other accounts, do not post the link in
  unrelated places.

## In Vonit

Posts and messages go out only as the person approved them, at the planned times
where the connection allows scheduling; replies are drafted for the person to
approve or rewrite - the person's voice matters most on this day.
